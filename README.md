### Featured work

**[AI Security & Governance Lab](https://github.com/Tozino22/ai-security-governance-lab)** · [live demo ↗](https://tozino22.github.io/ai-security-governance-lab/)
Three browser-based tools for assessing and teaching AI/LLM security: a hands-on
lab across the **OWASP Top 10 for LLM Applications**, an AI project risk advisor,
and a lifecycle navigator. Findings map to ISO/IEC 42001 Annex A, the NIST AI RMF,
MITRE ATLAS and the EU AI Act.

**[Security Assessment Framework](https://github.com/Tozino22/security-assessment-framework)**
Authorization-first assessment methodology across seven tracks — web, API, cloud,
container and supply chain, mobile (MASVS) and **AI/LLM systems** — with pass/fail
criteria, a field guide, and **AutoScan**, a Docker-orchestrated scanner gated on
written authorization.

**[Catalyst GRC](https://github.com/Tozino22/catalyst-grc-simulator)**
Multi-tenant GRC platform (Next.js + Supabase) that cross-maps a single control
across **SOC 2, PCI DSS 4.0, NIST CSF 2.0, NIST AI RMF and ISO/IEC 42001**, so a
technical finding moves the compliance position instead of sitting in a separate
report. Row-level security enforced at the database.

**[Risk Register Consolidator](https://github.com/Tozino22/risk-register-consolidator)**
Python tool that ingests risk registers with different layouts and scoring scales,
normalizes them to one master scale, flags likely duplicates for human review, and
shapes the output for import into Drata, Vanta or any CSV-accepting platform.

**[MapleFile — Security Controls Specification](https://github.com/Tozino22/maplefile-security-spec)**
A worked example of specifying security and AI-governance controls *before* a line
of code is written: SIN/PII tokenization ahead of any model call, retrieval-time
authorization, deterministic computation with the LLM confined to explanation, and
every control traced to a framework.

**[CV Reviewer](https://github.com/Tozino22/cv-reviewer)** · [live demo ↗](https://tozino22.github.io/cv-reviewer/)
Resume scoring against 16 hiring standards with an ATS parse check. Fully
client-side — nothing leaves the browser.
